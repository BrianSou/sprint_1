| Metric | Definition | Caveat |
|---|---|---|
| Volume by status | Count complaints for each current status | Does not show historical status changes |
| Volume by category | Count complaints in each category | Reflects currently recorded categories |
| Volume by month | Count complaints by received month | Receipt month, not closure month |
| Open backlog | Count complaints in unresolved statuses | Must update filters if new statuses are introduced |
| Escalated backlog | Count unresolved complaints with an escalation decision | A historical escalation may no longer be active |
| Distinct customers | Count unique customer IDs with complaints | Repeat complainants count once; missing IDs are excluded |
| Average resolution days | Total elapsed closure days divided by the number of qualifying closed complaints per category | Recorded closure timestamps may be unreliable; excludes unresolved cases |
